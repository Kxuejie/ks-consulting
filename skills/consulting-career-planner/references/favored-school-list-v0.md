# Favored School List V0

> 用途：供 `consulting-career-planner` 判断校招 & Summer 咨询求职背景时参考。
> 性质：经验型 favored list，不是 MBB/Tier2/Big Four 官方 target school 名单。
> 原则：优先参考常见中国区 MBB/Summer offer holder 背景；不在名单时查询最新 QS 排名并结合地区知名度判断。

---

## 一、使用原则

### 不要把名单当成绝对门槛

名单用于判断学校背景信号强弱，不用于直接宣判用户“能/不能”进咨询。

输出时避免说：
- “100%有面试”
- “这个学校一定能进”
- “不在名单就没机会”

建议说：
- “学校背景属于强信号”
- “具备主投 MBB/Tier2 的学校基础”
- “学校信号不足，需要靠更强实习和投递策略弥补”

### 不在名单时的处理

如果学校不在本名单：

1. 查询最新 QS 世界大学排名
2. 判断学校所在地区和目标 office 的认知度
3. 结合是否为国内 C9/985/211、强商学院、强工程学院、强医学院、强 LAC
4. 再给出学校背景档位

参考规则：

| 情况 | 学校背景判断 |
|---|---|
| QS Top 30 但不在 favored list | 最高按 Favored A- 处理；MBB 仍然很难，不自动视为 target 背景 |
| QS Top 50 但不在 favored list | 较强信号，通常不构成明显硬伤，但 MBB 不作为主线 |
| QS Top 100 但不在 favored list | 可接受，但需要实习质量支撑；更适合 Tier2/Big Four/Boutique 判断 |
| QS 100-200 | MBB/Tier2 需要谨慎，Big Four/Boutique 更现实 |
| QS 200+ 或知名度弱 | 学校是明显短板，除非有极强实习/竞赛/推荐 |
| 国内强 985/211 但 QS 不突出 | 不机械降级，结合本地知名度和实习判断 |
| 美国 LAC/专业强校 | QS 可能低估，需要单独判断 |

## 二、学校档位定义

| 档位 | 含义 | 对 MBB/Tier2 的影响 |
|---|---|---|
| Favored A+ | 极强学校信号 | MBB 学校维度强；若实习也强，可主投 MBB |
| Favored A | 强学校信号 | 具备 MBB/Tier2 主投资格，仍需实习支撑 |
| Favored A- | 较强学校信号 | Tier2/Big Four/Boutique 较稳；MBB 需强实习加持 |
| Strong Regional | 地区或专业强校 | 看目标 office 和实习质量，不能只凭学校冲 MBB |
| QS Supplement | 不在名单但排名/声誉强 | 查询后动态归档 |

### MBB 判断的保守规则

对 MBB 单独判断时，只有 Favored A+ / Favored A 可以作为学校维度的 target 背景。Favored A- 可以把 MBB 放入 stretch，但必须同时有强实习、强成绩、强推荐或其他明显亮点；Strong Regional、QS Supplement、单独判断学校默认不把 MBB 作为 target firm，只能作为低概率 stretch 或暂不建议。

## 八、初步学校评分建议

| 学校档位 | 学校分 |
|---|---:|
| Favored A+ | 5.0 |
| Favored A | 4.5 |
| Favored A- | 4.0 |
| Strong Regional / QS Top 100 | 3.0-3.8 |
| QS 100-200 / 普通 985/211 | 2.2-3.0 |
| 知名度弱 / QS 200+ | 1.0-2.2 |

使用提醒：
- 分数只用于内部判断，不一定要完整展示给用户。
- 学校分高但实习弱，不等于 MBB 稳。
- 学校分低但实习极强，可以把 MBB 放在 stretch，但不要作为主线。
- 医药咨询可以因专业和行业实习上调目标匹配度，但不应自动上调 MBB 学校分。
