## 使用规则

- 零基础教学第一次介绍算法时，同时展示需求侧漏斗和供给侧产能图。
- 进入例题后，把模板中的通用文字替换成题目变量和实际数字。
- 需求侧优先展示“总体如何逐层缩小”；供给侧优先展示“最大产能中实际利用了多少”。
- Mermaid 不支持或渲染不稳定时，使用同节提供的文本版本。
- 图只承担一个核心关系，不把全部计算塞进一张图。

## 需求侧基础漏斗

```mermaid
flowchart TD
    A["基础总体 100%"] --> B["目标客户：年龄、收入、地域等符合条件"]
    B --> C["有需求的人：真正需要该产品"]
    C --> D["实际购买的人：采取购买或使用行为"]
    D --> E["人均使用量或购买频次"]
    E --> F["销量 × 单价 = 市场规模"]
```

同时显示完整公式：

```text
购买人数 = 基础总体 × 目标客户占比 × 需求率 × 购买率
销量 = 购买人数 × 人均使用量或购买频次
市场规模 = 销量 × 单价
```

文本兜底：

```text
基础总体 100%
    ↓ 筛选目标客户
目标客户
    ↓ 筛选真正有需求的人
有需求的人
    ↓ 筛选真正购买的人
购买人数
    ↓ 乘人均使用量或频次
销量
    ↓ 乘单价
市场规模
```

## 供给侧产能容量图

用整个圆圈表示最大产能，用圆圈中的已利用部分表示实际产量：

```mermaid
pie showData
    title 产能利用率示意
    "实际利用的产能" : 70
    "未利用的产能" : 30
```

概念解释：

```text
最大产能 = 100% 的理论上限
实际产量 = 最大产能 × 产能利用率
闲置产能 = 最大产能 − 实际产量
```

文本容量条兜底：

```text
最大产能  |████████████████████| 100%
实际产量  |██████████████------|  70%
闲置产能  |--------------██████|  30%
```

基础教学可使用 70% 的示意数字。进入具体题目后，必须换成题目计算出的实际利用率；若没有可靠利用率，只展示概念关系，不伪造比例。

## 供给侧公式树

```mermaid
flowchart TD
    A["关键资源：人员、机器、座位、车辆或广告位"] --> B["单位时间最大产能"]
    B --> C["× 产能利用率"]
    C --> D["× 营业或运行时间"]
    D --> E["实际销量"]
    E --> F["× 单价"]
    F --> G["市场收入"]
```

同时显示完整公式：

```text
单位时间最大产能 = 关键资源数量 × 每个资源的单位时间产能
实际销量 = 单位时间最大产能 × 产能利用率 × 时间
市场收入 = 实际销量 × 单价
```

## 算法选择图

```mermaid
flowchart TD
    A["能否描述生产或服务流程并找到产能瓶颈？"] -->|"不能"| B["优先考虑需求侧"]
    A -->|"能"| C["结果主要受供给限制吗？"]
    C -->|"是"| D["优先考虑供给侧"]
    C -->|"否或不确定"| E["比较两条路径的假设数量"]
    E --> F["选择假设更少、更容易解释的一侧"]
    F --> G["必要时用另一侧做对标验证"]
```

## 混合算法图

```mermaid
flowchart TD
    A["需求侧：市场总需求"] --> C["总需求 ÷ 单点供给能力"]
    B["供给侧：单店或单设备承载能力"] --> C
    C --> D["所需门店、设备或服务点数量"]
```

典型公式：

```text
门店数量 = 市场总需求 ÷ 单店可承载需求
```
