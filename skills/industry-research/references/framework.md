# 空间 时间 深度研究框架

## 方法来源与核心逻辑

主来源为《战略咨询基本功课程》第1—6节行业认知系列，报告论证与表达衔接第10节及《如何做行业研究报告（结构与Storyline）》直播课。课程将行业定义为“围绕某项/某类型产品/服务的商业链条”，从输入、加工、输出推导出原材料 → 组合加工制造 → 销售 → 使用的基本流程。

空间梳理这个系统的构成与关系；时间研究系统如何变化；深度进入具体环节和企业，解释它们的运作与竞争。三维互相验证，可随研究目的调整详略，不是三个互不相干的信息清单。

| 维度 | 课程板块 | 研究应回答的问题 |
| --- | --- | --- |
| 空间 行业全景图 | 基本元：流程/产业链 | 产品或服务怎样从投入走到最终使用？各环节由谁完成？ |
| 空间 行业全景图 | 链接：价值流动与参与方关系 | 谁给谁提供价值、向谁付费？利润更容易留在哪里，为什么？ |
| 时间 行业演进规律 | 规模与驱动 | 市场有多大？哪些可拆解变量推动增长？ |
| 时间 行业演进规律 | 行业周期 | 当前处在什么阶段？下一阶段会改变什么？ |
| 时间 行业演进规律 | 外部变量 PEST | 政策、经济、社会、技术如何作用于产业链和增长变量？ |
| 深度 板块与公司运作 | 竞争环境 | 同一环节中谁与谁竞争？份额与壁垒怎样形成？ |
| 深度 板块与公司运作 | 商业模式 | 环节内部的小流程怎样运行？收入、成本、利润与成功条件是什么？ |
| 深度 按需延伸 | 单一公司理解 | 某家公司的经营机制、能力与策略为何不同？ |

## 空间：从产品走到参与方关系

### S1 流程与产业链

先定义边界，说明纳入/排除的产品、客户、地区和统计口径。先用一两句让新手知道“这行提供什么、帮谁解决什么问题、客户实际上拿到了什么”，再给产业链图。

产业链可以直接依据可靠研报、行业资料和企业披露整理，不要求自行从产品形态推导或重建已有产业链。保持研究框架独立，是指按自己的研究问题组织资料，不意味着产业链也必须原创。

沿用清晰的主要环节、投入产出、代表参与方和相互关系。制造、服务、平台按实际业务呈现，给新手补上必要的动作与术语解释。资料不完整时，才用产品形态、使用场景、销售地点或服务交付流程帮助补缺；这些属于可选思考辅助，不是报告必做步骤。

上游、中游、下游是相对研究对象的位置：电池在整车产业链中属于上游，以电池为研究对象时，它又成为中游，整车厂则是其下游。同一张图保持观察层级一致。付费者与使用者不同的行业分别列出。

### S2 从参与方地位解释利润分配

本节研究权力关系的目的，是判断哪些环节更容易获得利润，以及为什么。先给一句利润分配判断，再用关键事实和通俗原因解释，最后连接到价格、采购成本、收费或订单带来的利润。默认采用简明的行业解释，不展开严肃的替代方案评估或供应商尽调，也不要求量化每项换厂成本。

先看每个环节创造什么价值、谁向谁付钱。相邻交易中，一方的收入对应另一方的采购支出，各方都想多留利润，所以会有价格与条件上的博弈，也可能共同做大需求。产业链各层收入相加会重复计算，不等于终端市场规模。

课程的“行业周期初判 → 不可替代性修正”可帮助找原因：导入阶段可能缺关键投入，成长阶段可能依靠制造交付扩大规模，成熟阶段可能更依赖客户与渠道。结合本行业事实，选最能解释地位和利润的因素，不能只按周期给答案。

| 地位来源 | 要给读者解释的原因 | 怎样联系到利润 |
| --- | --- | --- |
| 技术限制 | 掌握什么关键技术，它解决什么问题，为什么能做好这件事的企业比较少？用普通话说明，不停在“技术壁垒高”。 | 其他环节需要这项能力，提供者就更有条件保留价格或收取技术带来的溢价。 |
| 监管或稀缺资源 | 谁掌握稀缺资源、准入资格、付款或购买渠道，为什么其他环节需要依赖它？ | 控制必要资源或通道的环节，在收费、采购或交易条件上更有影响力。 |
| 生态及网络效应 | 为什么用户、商家或配套服务聚集在这里，会让它更有价值？例如商家希望接触平台聚集的客户。 | 能带来客户或促成交易的环节，可能获得服务费或佣金；解释它具体提供的价值。 |
| 文化与品牌认知 | 消费者为什么认这个品牌，购买的是哪些功能以外的信任、体验或身份感？ | 消费者愿意为这些价值多付钱，品牌方更可能留下相应的利润空间。 |

渠道掌握客户、规模采购、供需紧缺或过剩也可用于解释。挑本行业真正重要的原因即可，不要求四类全部展开；每个主要判断至少解释“地位为什么高/低 → 怎样影响利润”。必要时可用五力中的供应商、购买者等视角辅助，同环节竞争在 D1 展开。

有可比的利润数据就用来支持判断；没有时可以依据行业事实给出有方向的定性判断，标明这是分析推断，不编造精确分成。说明讨论的是利润总额、利润率还是利润获取能力，不把三者混为一谈。仅保留会实质改变结论的限制，避免大段谨慎表述淹没主要判断。

本维度收束：行业怎样运作，利润更容易留在哪些环节，这些环节地位更高的原因是什么。

## 时间：规模模型 → 驱动变化 → 阶段与传导

### 规模与驱动

选择适合本行业的公式，写清每个变量的单位和时间段。

先从“收入 = 价格 × 销量”识别量与价，再选择需求侧或供给侧。需求侧按“总人群/企业 → 有需求 → 认识并考虑该方案 → 愿意且具备购买条件 → 实际购买”逐层筛选；各比率注明分母，避免有重叠的比例重复相乘。只有研究某公司时才继续乘品牌份额。供给侧先指出限制交付上限的人、设备、场地或其他瓶颈，再估容量与利用率；生产量能否转成销售量还需检查库存、需求和交付。

- 消费品：年度市场收入 = 目标人群 × 年内购买比例 × 年购买频次 × 每次购买量 × 单位价格。
- 企业服务：年度收入 = 目标企业数 × 付费渗透率 × 年均每客户收入。若客单价已是年费，不再乘购买频次。
- 耐用品：年度销量 = 新增需求 + 替换需求；稳定状态下年替换量可估为保有量 ÷ 平均替换年限。渗透率的存量变化与当年购买比例不同。
- 供给约束行业：年度供给量 = 单位时间产能 × 时间 × 利用率；若使用年产能则不重复乘时间。
- 平台：GMV = 交易量 × 均价；平台收入另按抽佣、服务费等计算。不要把 GMV 直接当平台营收。

以上是适配示例，不要求所有行业套一个公式。行业规模不乘某品牌购买概率；只有计算公司销量/收入时才加入份额。地区口径为国内消费时，出口不计入国内市场；研究生产或全球销售时另行定义。

比较可比的历史数据，区分量增、涨价与结构升级。沿课程的三个需求变量向下追问：

- **人口或客户基数**：总人数与目标群体分别怎么变？年龄群体看对应出生队列及迁移等因素，不能用当年出生率直接解释当年的成年客户。企业服务则看目标企业数和类型。
- **渗透率**：认知/接受度 → 购买与使用的总成本及便利性 → 购买力与预算 → 实际转化。说明限制卡在哪一层；知道产品不等于愿意买，愿意买不等于支付得起。
- **频次与数量**：使用场景是否增加、每次数量是否增加、替换周期是否缩短？耐用品保有量、年销量和替换量分开；不能重复计入已包含在客单价中的频次。

价格单独判断成本传导、通胀、产品结构、技术降本、竞争降价和支付政策等影响，不能预设所有行业价格基本不变。涨价可能压低销量，需要讨论量价互动。政策与需求也可能共同作用，不把“政策驱动”自动等同不可持续。

每条驱动力按“变量发生什么变化 → 为什么 → 对总量/价格的贡献 → 还有多少空间及限制”展开，区分一次性改善与持续增长。宏观代理公式可在关系有依据时使用，写清局限。增长预测使用条件情景，解释关键假设；不为凑图表虚构历史序列。

### 行业周期

综合渗透率、增速、竞争进入/退出、盈利和供需状态判断导入、成长、成熟或衰退。不同细分市场可处不同阶段。区分长期生命周期与短期库存、价格或产能周期。

课程的方法有两步：先判断当下，再用下一阶段的机制提出可验证的未来假设。报告要解释消费者、供需和竞争为何共同产生这些特征。

| 阶段 | 机制及典型表现 | 企业重点与转折信号 |
| --- | --- | --- |
| 导入 | 产品/服务仍在验证，使用门槛高，客户较少，研发或教育市场投入可能使盈利偏低；技术路线之间也可能激烈竞争。 | 验证需求与交付、保住现金、避免过早扩产。可用性提升、客户扩大、单位经营改善是进入成长阶段的信号。 |
| 成长前期 | 接受度与可得性提高，新客户增长快，新增需求给多类玩家空间，也吸引进入者。 | 扩大交付、建立品牌和差异化；检验供给是否开始追上需求。高增速不等于所有公司都能盈利。 |
| 成长后期 | 尚未购买的目标客户逐步减少，前期扩张的供给增加，争夺客户更困难，出现价格压力与盈利分化。 | 关注成本、差异化和扩产节奏；增速持续放缓、供给过剩、尾部退出可提示向成熟转变。 |
| 成熟 | 新增客户有限，替换、复购及争取其他品牌客户变重要；渠道效率、服务和成本更影响胜负。 | 经营效率、客户留存、适用的产品升级或新市场。成熟可持续很久，替换需求能支撑规模。 |
| 衰退 | 需求消失或转向替代方案，原产品需求持续缩减，玩家退出和产能收缩；可能保留小众市场。 | 评估剩余需求、退出与转型成本、现金和利基市场，不能仅因高渗透率断定必然消失。 |

服务业还要看使用频次、留存与需求是否被新服务替代；“很多人试过”不代表使用已经成熟。每个阶段输出当下判断、支持证据、反向证据、下一阶段及可观察的触发信号，建议必须解释为何适用于该阶段和该类公司。

课程与旧方法论中的渗透率/增速区间是教学速查，不是跨行业统一阈值；低渗透率不自动等于导入期，高渗透率不自动等于衰退期。给出支持与反对当前阶段判断的证据，以及观察下一阶段的指标。

### PEST

完整考虑政策、经济、社会、技术，重点展开影响最大的变量。政策看激励、限制及跨境关系；经济看消费/企业预算、融资和成本；社会看目标客群、习惯与接受度；技术区分“改善原产品”和“另一个方案替代原产品”。环境与法律因素有实际影响时补入相关机制，不为凑栏目平铺。

按“外部变化 → 影响谁的行为或成本 → 规模公式或环节关系变化 → 企业表现”解释传导，附时间范围与条件。技术说明先解释它解决哪个问题，再比较现有方案的性能、成本和交付限制；政策说明区分已实施、已发布待实施与提案。避免把政策名称和热点列表当作分析。

本维度收束：增长来自哪里、持续性如何，以及变化会重新分配哪些环节的话语权和利润。

## 深度：在关键环节解释企业如何胜出

根据前两维结果选择值得深入的环节，并说明理由，例如最大利润池、增长来源、瓶颈或用户指定重点。全景可覆盖所有主要环节，深入程度围绕问题分配。

### 竞争环境

在同一市场边界内比较公司或公司类型的客户、产品、份额、技术、成本、渠道和交付能力。CRn 必须同地区、同年份、同产品口径；缺少份额时用有出处的定性格局，并说明不能精确计算集中度。

集中度不直接决定利润率，不能套用“CR5达到某值所以净利率必然是多少”。解释份额如何形成、壁垒是否可持续，以及潜在替代和新进入者可能改变什么。

先说明集中度衡量的是“头部合计占多少”，竞争激烈程度还要结合产品差异、价格行为、供需和进入退出。课程中的格局与策略对应关系用于形成问题：

| 格局倾向 | 要论证的竞争机制 | 按条件考虑的策略 |
| --- | --- | --- |
| 单一玩家占优 | 客户为什么无法转向其他公司，限制是否会松动？ | 头部维护核心能力、注意规则与替代；其他公司寻找明确未满足需求或技术变化。 |
| 少数玩家主导 | 少数对手彼此反应是否造成价格压力，差异化如何减轻直接替代？ | 比较差异化、渠道、成本；小玩家看局部突破、定制需求或合作，合并不自动创造价值。 |
| 玩家众多且可差异化 | 客户按哪些需求分群，品牌/服务是否带来可维持的偏好？ | 头部看品牌与效率，其他玩家看细分需求与新渠道；说明为什么该需求未被满足。 |
| 产品接近同质化 | 客户为何主要按价格选择，成本差异来自哪里？ | 单位成本、周转与响应速度；垂直整合需衡量规模与新增投入，不能当通用答案。 |

拆解代表玩家时，可比较产品线/差异化/迭代、价格带/走量或溢价、渠道覆盖/控制、供应链自建或外包/成本来源、营销品牌。按“具体动作 → 改变客户选择或经营效率 → 经营结果 → 可复制条件”论证，不能因为龙头做了某件事，就断言这件事导致它成功。

### 商业模式

对重点环节再做一次“投入 → 生产/交付 → 销售 → 使用”的小流程分析：为谁创造什么价值，谁付钱，按什么计费，主要成本在哪里，何时回款，需要哪些资产和能力。

课程在此研究一类公司的运作，默认不套用单公司商业画布。用“支出从哪些环节发生，收入向谁取得”解释利润；中间商的佣金收入不能误写为采购成本减少。按实际模式选择以下细分框架，并讲清指标与利润的关系。

| 模式 | 环节内流程 | 利润与效率的具体研究方向 |
| --- | --- | --- |
| 原材料/上游供应 | 原始资源采购 → 加工成符合要求的材料 → 向下游企业销售 | 资源取得成本、加工损耗、合格率、交付可靠性；选哪些下游客户、怎样提高企业销售转化及维持关系。 |
| 设计制造/品牌商 | 采购 → 设计 → 加工组装 → 销售 | 分开设计、制造和品牌价值，说明外包/自建的取舍；材料替换不能牺牲关键功能；比较品牌、产品差异化与渠道管理怎样改善价格或销量。 |
| 经销与零售 | 进货 → 仓储/物流 → 陈列与销售服务 → 终端客户 | 购销差价、库存、损耗、人员和场地效率；直销与经销改变谁承担库存、获客及服务成本，解释覆盖和控制的取舍。 |
| 多品类零售 | 选品 → 配货陈列 → 售卖补货 → 调整商品组合 | 货架空间或线上注意力有限，商品毛利和销售速度共同决定使用资源的效果；不能只选毛利率最高但卖不动的商品。 |
| 商场运营 | 招商 → 提供场地/服务 → 吸引客流 → 续租与组合调整 | 直接付费者通常是商户，收入可能为租金和营业额分成；解释店铺组合如何吸引消费者，并影响租金、出租率与成本。按真实合同确认模式。 |
| 中间商/平台 | 吸引供需两侧 → 筛选与匹配 → 促成交易 → 维护两侧 | 分别看两侧数量与质量、匹配效率、每笔交易留下的收益；识别向哪边收费、哪边补贴，扣除获客、履约、服务和风控等成本。 |

**企业客户销售的小流程**：潜在客户 → 确定意向 → 需求分析/方案 → 演示与谈判 → 签约 → 客户维系、续约与增购。先解释使用者、采购、预算负责人等为何参与，再看每一步的转化、耗时和成本，找到阻塞点。企业客户与个人消费者的决策人数、金额、合同和风险常有差异，但不能概括为“企业一定理性、个人一定感性”或“企业转换成本一定高”。

**渠道细分**：线上看触达 → 点击/访问 → 咨询或加购 → 下单 → 复购的转化；线下看覆盖、客流、成交、客单与复购。制造商面向经销商销售时，还需区分发货给渠道和卖给终端，解释库存及压货对收入判断的影响。DTC 指品牌直接面向消费者销售，可增加控制，也可能新增获客、门店和服务支出。

**零售指标的小框架**：SKU 指按具体规格独立管理库存的商品单位，颜色或尺码不同通常分别管理；动销率 = 期内有销售的在售SKU数 ÷ 在售SKU数，反映商品组合是否存在大量滞销；单品日均销量 = 期内销量 ÷ 天数，反映售卖速度；坪效 = 期内销售额 ÷ 经营面积；库存周转率常用期内销售成本 ÷ 平均库存成本，衡量库存循环的快慢。说明周期、单位和口径，区分日销量与库存周转，不能只给指标名。

**平台指标的小框架**：供需两侧数量和质量 → 可匹配程度/成交转化 → 交易次数与客单 → 交易额 → 抽佣及其他收入 → 扣成本后的收益。解释更多商户能否增加有效选择、是否同时带来低质或拥挤；提升抽佣可能使商户退出，不能只看单边指标。订阅服务补充付费客户、续费、增购和交付成本，不能重复将年费乘购买频次。

没有数据时提供机制和待验证项。公司建议按“动作 → 改变哪个指标 → 为什么改善收入/成本/现金 → 代价和前提”表达，避免停在“降本增效、加强品牌、拓展渠道”。

从经济机制推导成功关键因素，并说明成立条件；再解释头部、细分玩家或新进入者的可行动方向。单一公司深入只在用户要求或确实有助于核心判断时增加，不把整份行业报告写成某公司介绍。

本维度收束：在行业变化之下，哪类商业模式或能力更有优势，依据是什么。

## 综合洞察

用连贯推导写核心判断：空间里的瓶颈或价值关系，如何受到时间变量影响，又如何改变深度层面的竞争和盈利。每条包含结论、证据、因果、适用边界及最关键的反证或待观察变量。

## 逐板块覆盖检查

本表用于检查上文方法是否实际落实，不替代上文完整方法。研究开始时按板块列问题与证据需求，完成底稿和格式转换后分别核对。编号与 SKILL.md 的骨架对应，详细要求在本文件维护。

| 编号 | 板块 | 正文中应能找到的实际分析 |
| --- | --- | --- |
| S1 | 流程与产业链 | 基于可靠资料呈现主要环节、投入产出、参与者及关系，并解释新手不熟悉的动作和术语；不要求原创推导产业链。 |
| S2 | 价值流动与参与方关系 | 谁向谁提供什么、谁向谁付费；哪些环节更能获得利润；用关键事实和通俗原因解释地位高低及对利润的影响，无需逐一审查替代方案。 |
| T1 | 规模与驱动 | 市场规模的口径、时间、单位及来源或缺口；适配本行业的规模公式；人口/客户、认知与购买转化、频次、价格怎样变化并驱动增长。 |
| T2 | 行业周期 | 渗透率、增速、竞争与盈利/供需等证据如何支持阶段判断；解释阶段特征为何出现、下一阶段如何变化，服务业按需补充频次。 |
| T3 | PEST | P/E/S/T 均经过相关性判断；重点变量如何传导到量、价、成本或参与方关系，并说明条件和时间范围。弱相关项简述，不强行编造影响。 |
| D1 | 竞争环境 | 选定深入环节及理由；同一市场边界内的玩家比较、份额或定性格局；壁垒、竞争机制及可能的变化。 |
| D2 | 商业模式 | 选择适用的环节小流程、企业销售/渠道/零售/平台方法；解释收入、成本、利润与指标的联系，再推导成功关键因素。 |
| D3 | 单一公司理解 | 需要时解释具体公司的机制、能力差异和策略依据；未研究时记录本次未要求公司深挖。 |

在研究底稿末尾保留简短核对表，字段为“板块编号、正文位置、关键证据/推导、状态及原因”。状态使用“已覆盖”“资料不足”“用户限定范围省略”“按需未启用（仅D3）”。“已覆盖”要求完成对应问题的分析，有标题、术语或数据罗列不算完成；“资料不足”要求明确哪项无法判断及其影响。

跨维度再检查一次：S2 中识别的关键关系，是否与 T1—T3 的变化相联系，并进一步解释 D1—D2 的竞争或盈利变化。结论中应出现有证据支持的完整推导，不能只把三维摘要拼接在一起。

核对表用于执行与维护，默认不放进对外报告。影响结论的资料限制和范围取舍必须保留在对外正文。导出 HTML/Word 时核对各板块的分析、表格和限制说明都已转入，不以标题数量充当一致性检查。

方法覆盖之外，按 [论证与表达](reasoning-and-writing.md) 检查前置观点、通俗原因和文末术语章。拥有数据与板块标题不能替代“为什么”的解释。
