# 面向新手的论证与表达

生成任何行业研究正文前必读。本文件落实第10课的观点与事实、金字塔表达，以及行业研究直播课的 Storyline 方法；用户要求优先保留充分的通俗解释，不把课程中口头汇报的“少讲细节”理解为报告可以省掉论证。

## 读者与研究目的

默认读者聪明、认真，但完全不熟悉这个行业。不要假设读者知道关键产品、技术、交易惯例或指标。先交代产品/服务、解决的需求、参与方和交易，再展开判断。必要细节放在其支撑的观点下，不无目的堆背景。

默认目的是让读者理解行业、趋势和企业成功条件。用户明确要求公司建议时，在同一三维研究中补足该公司的能力和条件。保留三维分析骨架；直播课其他报告骨架用于理解研究目的和观点衔接，不覆盖本 skill 的固定结构。

## 基本论证单元

每个分析小节、关键数据组和图表都应遵循：

**一句观点判断 → 事实依据 → 通俗的机制解释 → 影响及必要边界。**

- **观点判断**说明“这些数据代表什么”，不是重复数字或写“市场规模”“集中度分析”这样的主题名。主体、方向与条件要明确，例如“供给扩张快于需求，正在削弱供应商的提价能力”。证据只能支持倾向时写“可能”“更支持”，不能为了先有结论而编造确定性。
- **事实依据**给出支持判断的关键数据、具体做法或观察，附来源、时间、单位及口径。使用“大、快、高、低”要有合理参照；只有一个孤立数字就说明无法判断相对高低。
- **机制解释**回答这些事实为什么支持判断，把中间环节讲出来。不能“市场集中度高 → 所以竞争不激烈”，应检查客户替代选择、产品差异和实际价格行为；也不能“研发费高 → 所以技术不可替代”。
- **影响和边界**说明对哪类参与方、什么经营变量有影响，哪些条件改变会使判断失效。局部改善不能直接放大成全行业结论，相关变化不能直接包装成因果证据。

把这四层写成自然段，不必每段都贴四个标签。一个连贯论证可以用几段承载，事实表的每个单元格不必强塞一套论证。关键小节必须完整，来源目录和术语词条不强行写观点。

解释以读者理解商业逻辑为尺度，通常选最重要的原因讲透即可。尤其产业链权力关系，重点是“谁更能留下利润、为什么地位更高”，不写成替代方案审查或供应商尽调。没有精确利润数据时，可以给有依据的定性判断；限定条件只保留会影响主结论的部分。

## 技术或行业细节怎样解释

首次出现关键术语时，用一句普通话解释，然后回答它在本行业中做什么、为什么与当前判断有关。英文缩写附中文名称；仅写英文全称不算解释。

解释某项技术时沿“它解决什么问题 → 怎样起作用（足以理解本段的程度）→ 相比现有做法改变什么 → 实际使用受什么限制”展开。可用生活类比辅助，但说明类比对应哪一点；类比不能代替真实技术机制或被当成事实证据。

解释行业流程时尽量使用具体主体和动作。例如，把“渠道优势强”展开为“这类经销商掌握着品牌难以直接接触的当地门店，能帮助产品进入更多销售点，所以在向品牌拿货时更有谈价空间”。具体判断依据本行业资料，不要求列出所有可能的交易方案。

对“技术壁垒、不可替代、生态、协同、赋能、规模效应、认证、良率、产能利用率”等词检查：能否继续回答“具体指什么、怎么发生、影响谁”？若只能换另一组术语重说一次，需要重写。

## 数据与图表的呈现

先写解释该组数据的一句判断，再给表格或图表，随后解释最关键的因果和限制。图表标题可采用观点句，图注提供指标名、单位、统计范围与来源。增长率说明基期；市场份额说明分母；总额与利润率说明比较口径。

小白读者既需要知道数字，也需要知道参照物。比率可翻译为“每100个中约有多少个”，但不要让近似口语表述改变精确计算。预测图必须和历史事实区分，并解释情景假设。

框架标签与观点分工不同：一级标题和目录保留“空间、时间、深度”方便定位；每节紧接一句判断，小节标题或首句也承担具体观点。不能为了标题连读测试删掉框架，不能为了保持框架标题而省掉观点。

## 从局部判断到全篇主线

课程的三层结构在长报告中转为“小节观点 → 维度结论 → 全篇主线”，不把 HTML 或 Word 强行切成 PPT 页。

先搭研究问题，初步浏览资料后形成可推翻的工作假设，定向找支持和反向证据，再修改判断和标题。假设先行不等于只找能证明预设结论的材料。

导出前做两次连读：

1. 只读各小节的观点，检查它们能否支持相应维度的结论。
2. 只读三个维度的结论及综合洞察，检查能否讲清“行业如何运作 → 什么正在改变 → 这些变化怎样影响企业盈利与竞争”。

若缺一个因果环节，回到正文补证据或降低结论强度。不要用“因此、可见、由此”掩盖没有解释的跳跃。资料不足时允许主线以有边界的判断收束，不必包装成一个确定的成功故事。

## 文末固定章节 行业术语解释

最终报告在“来源与研究限制”之后，固定增加最后一章“行业术语解释”，HTML 和 Word 均保留。词条来自本次正文实际使用的专有词、技术名词、商业模式和指标；优先解释会阻碍读者理解判断的词，不按固定数量凑词。

每个词条包含：

- 术语及常用缩写；有英文名称时附全称。
- 一句通俗定义，不能只翻译英文。
- 在本行业哪个环节使用、起什么作用。
- 一个帮助理解的简短例子，或与近似概念的区别；示意例子明确为示意。
- 容易混淆之处或适用限制；指标注明单位、公式和时间口径，技术词说明与相关技术的区别。

定义需要准确，不靠词面猜测。优先核对标准、主管机构、原厂技术说明等可用权威资料；专业定义引用沿用正文来源编号，必要时在词条内补充可点击来源。正文首次出现时仍需就地解释，词汇表承担复习和查阅作用。

HTML 可用简洁词条卡或定义列表，每个词一个锚点；正文链接到词条是可选增强。Word 用“术语名”小标题和自然段，词条简短且比较维度一致时也可用表格。长解释不要塞进狭窄表格。

## 改写示例

以下为虚构材料，仅用于演示推导，不是可引用的行业事实。

**给定材料**：某虚构服装行业样本中，品牌商毛利率55%，代工厂15%；品牌商负责设计与营销，消费者愿意为该品牌多付钱；代工厂按订单生产，面临同类工厂的报价竞争。

**不充分的写法**：品牌商地位高、毛利率55%，代工厂地位低、毛利率15%。

**符合要求的写法**：

> 在这组样本中，品牌环节比代工环节更容易留下毛利，因为品牌影响了消费者愿意付多少钱。品牌商的毛利率为55%，代工厂为15%；品牌负责设计和营销，消费者也愿意为它多付钱。
>
> 消费者买的不只是衣服的材料和缝制，也在为喜欢的设计和品牌形象付钱。品牌掌握着这部分消费意愿，因此更有条件获得较高售价。代工厂主要赚生产加工的钱，又要与其他工厂比报价，利润空间更容易被压缩。这里比较的是毛利率，品牌后续的营销和管理开支还会影响最终净利润。

**对应术语词条**：

> 毛利率：收入扣除销售成本后，剩下的毛利占收入的比例。55%的毛利率可以理解为每卖100元商品，在扣除对应销售成本后留下55元；这还没有扣除所有营销、管理等费用，因此不等于净利率。

## 内容验收

- 从 S2、T2、D1、D2 各选一个关键判断，能否找到前置观点、事实、机制和边界？资料不足项是否诚实说明，而不是用强观点补位？
- 删除“高壁垒、不可替代、龙头优势”等标签后，剩余正文是否仍解释清楚为什么？
- 大、小、快、慢和高、低是否有适当的比较依据？
- 新手能否复述主要产品、参与方、交易和技术的作用，是否需要跳出报告搜索才能理解核心论证？
- 文末是否包含实际使用的重要术语，正文首次出现的解释是否保留？
- HTML、Word 是否都保留观点、机制段、来源、限定条件及完整术语章，不能在压缩排版时只留下结果卡片。
