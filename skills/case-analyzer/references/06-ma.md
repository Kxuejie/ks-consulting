# M&A｜运行型精简框架

## 用途

用于回答“某个 Target 是否值得收购，以及该交易是否适合收购方”。

核心逻辑是：**Target 本身是否有吸引力 → 价格是否合理 → 收购方能否通过交易创造并实现价值**。好公司不一定是好交易，合理估值也不代表收购方具备整合能力。

## 一、Target 是否有吸引力｜Target Attractiveness

### A. Target 所在行业

#### 板块目的

判断 Target 的未来表现是否受到有吸引力且可持续的行业环境支持。

重点分析：

- **Size**：行业与相关细分市场是否足以支撑交易目标；
- **Growth**：历史增速、未来趋势及其底层驱动是否可持续；
- **Competition**：集中度、领先玩家、替代品与进入壁垒；
- **Economics**：如材料提供，关注利润率、资本强度、现金流和周期性。

同业并购时，行业背景可以压缩，把重点放在 Target 相对表现；跨行业转型或投资型收购时，应更充分验证行业吸引力。

#### 行业阶段性判断方向

明确行业环境对收购是支持、中性还是削弱，并指出最关键的增长驱动或结构性风险。

### B. Target 的业务

#### 财务现状

观察 Revenue、Cost、Profit、Margin、Cash Flow 或题目提供的关键指标：

- 与 Target 自身历史比较；
- 与行业和可比公司比较；
- 与收购方相近业务比较；
- 区分一次性波动与持续经营趋势。

增长快但现金消耗过大、利润主要依赖一次性因素或明显弱于行业，都可能降低吸引力。

#### 竞争优势与核心资源

识别真正能维持 Target 表现的资源，例如客户关系、品牌、技术、专利、数据、成本、渠道或生产能力。

每项优势都要说明：

- 是否稀缺、可防御；
- 收购后能否保留；
- 是否依赖关键人员或特定合同；
- 如何转化为收入、成本或战略价值。

#### 未来发展

评估现有业务增长空间、新产品 / 市场计划与行业趋势的匹配。不要直接接受管理层预测；用历史执行能力、资源要求和行业条件校验。

#### Target 业务阶段性判断方向

明确 Target 是优质资产、可改善资产还是高风险资产，并指出判断主要来自财务表现、竞争优势还是未来增长。

### C. 标的价格是否合理

价格判断应尽量使用多种方法交叉验证，但只展开 Casebook 提供数据所支持的方法。

#### DCF

`Enterprise Value = Present Value of Forecast FCF + Present Value of Terminal Value`

重点检查：

- FCF 预测是否与业务分析一致；
- Discount Rate 与风险是否匹配；
- Terminal Growth 是否低于长期可持续水平；
- Synergy 是否已经计入现金流，避免重复估值。

DCF 对关键假设敏感，应至少说明增长率、Margin 或 Discount Rate 变化对估值方向的影响。

#### Multiples

选择业务模式、增长、利润率和风险相近的可比公司或交易，使用 EV/EBITDA、P/E、EV/Sales 等适合指标。

可比倍数不是机械平均值。Target 若增长和质量更好可以支持溢价，风险更高则应折价。

#### Book Value

适用于资产密集、清算价值重要或题目明确要求的场景。账面价值通常不能充分反映品牌、技术和未来增长，不应单独决定交易价格。

#### 估值阶段性判断方向

给出合理价值区间，并明确 Offer Price 相对区间是折价、合理还是溢价。若存在溢价，说明需要多少可实现的协同才能填补。

### Target 吸引力的阶段性总结方向

综合行业、业务与估值，明确 Target 是否值得继续收购，并列出最重要的 2-3 个依据。不能因为 Target 是好公司就忽略价格。

## 二、收购方能力与匹配度｜Buyer Fit

### 板块目的

判断该 Target 对“这家收购方”是否创造价值，以及交易完成后价值能否真正实现。

### 公司目标

明确交易要实现的目标，例如规模、增长、技术、渠道、成本、产业链控制或战略转型。将目标转化为可衡量结果，如 Revenue、Profit、市场份额、能力补齐或时间节省。

若 Target 无法直接推动核心目标，即使本身优秀，也不应成为优先交易。

### 价格、预算与回报预期

第一部分判断价格是否接近资产的合理价值；本节点判断收购方是否负担得起，以及交易后回报是否达到公司门槛。

关注：

- 预算与融资能力；
- ROI / IRR / Payback；
- 收购溢价；
- 融资成本和财务风险；
- Downside 情景下的承受能力。

### Synergies & Cannibalization

协同可以来自 Revenue、Cost、资本或能力，但必须说明价值来源、实现时间和一次性整合成本。

检查新业务是否挤压现有品牌、客户、渠道或产品。推荐应基于净协同：

`Net Synergy = Gross Synergy - Cannibalization - Integration Cost`

### 品牌影响

判断品牌定位是否互补、客户认知是否冲突，以及是否需要保留独立品牌。只在品牌确实影响交易价值时展开。

### 管理与文化整合

重点检查：

- 管理方式与决策速度；
- 关键人才保留；
- 系统、流程和组织重叠；
- 地域或文化差异；
- 整合责任与时间。

整合难度必须与协同可实现性连接；不能把文化风险当作通用尾项。

### 阶段性总结方向

本板块结束时必须明确：

1. Target 是否符合收购方目标；
2. 价格与回报是否在可接受范围；
3. 净协同是否足以覆盖溢价和整合成本；
4. 收购方是否有能力完成整合；
5. 最终 Buy / Do Not Buy 方向。

风险和前提可以限定结论，但不能替代选择。

## Case-specific 使用规则

1. 保留“Target 吸引力 → Buyer Fit”的一级顺序。
2. 估值只使用材料支持的方法，不为完整性强行同时计算 DCF、Multiples 和 Book Value。
3. 区分“合理价值”与“收购方可接受价格”，避免两个价格节点重复。
4. 协同必须扣除蚕食与整合成本，不能只列潜在好处。
5. Casebook Sample Calculation 只用于复核，估值输入必须追溯至 Candidate Material。
6. 最终 recommendation 第一行明确 Buy 或 Do Not Buy，再给依据、风险和下一步。
