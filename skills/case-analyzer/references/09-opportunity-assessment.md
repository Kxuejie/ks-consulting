# Opportunity Assessment｜运行型精简框架

## 用途

用于回答两类问题：

- **Do / Do Not**：某个机会是否值得做；
- **Choose A / B**：若干机会中应该选择哪个。

核心逻辑是：**机会本身是否有吸引力 → 外部环境是否支持 → 该机会是否与公司目标和能力匹配**。最终必须选择一侧，不能用“都可以”代替判断。

## 标准骨架

1. **机会是否有吸引力｜Opportunity Attractiveness**
   - 微观因素
     - 机会 / 产品 / 服务是什么
     - 客户价值与优缺点
     - 竞争力
     - 经济效益：Cost、Benefit、ROI
     - 对公司的短期影响与长期价值
   - 宏观因素
     - 市场环境与 Timing
     - 政策法规
     - 现有与潜在竞争
   - 其他机会（可选）
2. **是否与公司匹配｜Company Fit**
   - 公司目标与内部回报门槛
   - 公司能力与资源
   - 净 Synergies & Cannibalization

## 一、机会是否有吸引力｜Opportunity Attractiveness

### A. 微观因素

#### 定义机会

先说明机会具体改变什么：

- 产品或服务的核心功能；
- 面向哪个客户和使用场景；
- 如何交付或运营；
- 与当前做法相比发生什么变化。

定义只需消除歧义，不展开完整产品设计。

#### 客户价值与优缺点

判断机会是否解决重要痛点，并说明对客户、供应商、渠道或其他关键参与者的价值。

优点必须转化为可观察结果，例如更高转化、留存、速度、质量或更低成本；缺点应聚焦最可能抵消这些价值的 1-2 项。

#### 竞争力

与现有解决方案和主要竞争者比较：

- 是否具有可感知差异；
- 优势是否容易复制；
- 是否具备成本、品牌、技术、渠道或体验优势；
- 客户切换成本与替代意愿。

市场上“有人已经做过”既可能证明需求，也可能提高竞争门槛，需要结合差异化判断。

#### 经济效益

根据题目计算或判断：

- Initial Investment；
- Fixed Cost 与 Variable Cost；
- Incremental Revenue / Cost Saving；
- ROI、IRR 或 Payback；
- Downside 情景。

重点比较“做”与“不做”的增量影响，不把现有业务收入全部归因于机会。

若为 A/B 选择，对两项使用相同口径和时间范围。

#### 对公司的短期影响与长期价值

- **短期**：现金流、培训、运营复杂度、客户体验或声誉；
- **长期**：品牌、客户关系、数据、能力建设或战略选择权。

无形价值应解释作用机制，不能用于掩盖经济性不佳。

### B. 宏观因素

只分析会改变机会结果的外部条件：

- 市场发展与客户行为；
- Timing 与技术成熟度；
- 政策、监管和合规；
- 现有竞争者的反应；
- 潜在进入者与替代方案。

宏观背景必须说明如何影响需求、成本、可执行性或风险，不写成通用 PEST 清单。

### C. 其他机会（可选）

只有题目允许重新定义选项，且给定机会明显不是最佳选择时，才简要提出一个更接近公司目标的替代方向。默认不展开额外 brainstorm。

### 阶段性总结方向

本一级板块结束时必须明确：

1. 机会本身是否具有吸引力；
2. 客户价值、经济性和外部环境分别支持哪一侧；
3. 最大价值来源；
4. 最大不确定性。

如果是 A/B 题，分别对 A 与 B 做同口径判断。

## 二、是否与公司匹配｜Company Fit

### 板块目的

判断一个有吸引力的机会是否适合“这家公司”，以及公司能否把潜在价值真正实现。

### 公司目标与回报门槛

确认机会是否推动核心目标，例如增长、利润、留存、品牌、效率或战略转型，并与公司内部 ROI / IRR / Payback 门槛比较。

目标应有优先级。若短期利润与长期能力冲突，要说明当前公司更重视哪一个。

### 公司能力与资源

只分析执行机会所需的关键能力：

- 资金与现金流；
- 技术、产品或数据；
- 人才与管理；
- 供应链、运营或渠道；
- 品牌和客户关系。

对每项能力判断“已有、可建立、需合作或明显缺失”，并说明能力缺口对成本、时间和成功率的影响。

### Synergies & Cannibalization

评估机会能否复用现有客户、渠道、技术、品牌或后台资源，同时检查是否挤压现有产品、客户、收入或管理注意力。

用净影响判断，不只列协同：

`Net Value = Opportunity Value + Synergy - Cannibalization - Execution Cost`

### 阶段性总结方向

明确公司是否应选择该机会，以及公司目标、能力与净协同如何支撑结论。若机会有吸引力但公司不匹配，也必须明确选择 Do Not Do 或优先其他选项。

## A/B 选择规则

对 A 和 B 使用同一套比较表，不分别写两套散乱分析：

| 维度 | 机会 A | 机会 B |
|---|---|---|
| 客户价值与竞争力 | | |
| Incremental Economics | | |
| 外部环境与 Timing | | |
| 公司目标匹配 | | |
| 能力要求 | | |
| Net Synergy / Cannibalization | | |
| 核心风险 | | |

比较后必须选择 A 或 B，并解释决定性差异。只有题目明确允许时，才可选择“都不做”或分阶段组合；不能为了回避取舍而建议同时做。

## Case-specific 使用规则

1. 保留“机会吸引力 → 公司匹配”的一级顺序。
2. 机会描述只用于建立共同口径，不扩展为完整产品或实施方案。
3. 经济性优先计算增量 Cost / Benefit，并与公司门槛或可比机会比较。
4. 宏观因素只保留真正影响 Timing、需求、成本或可行性的 1-3 项。
5. A/B 题使用统一维度并排比较，最终明确选边。
6. 对 Missing 节点形成方向性工作假设，不编造市场数字或公司事实。
7. 最终 recommendation 第一行给 Do / Do Not 或 A / B，再给依据、风险和下一步。
